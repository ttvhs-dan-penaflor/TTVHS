TTVHS Learning Hub – test setup

1. Open the existing Google Sheet:
https://docs.google.com/spreadsheets/d/1Ggn1frnZruTljRvx2m2-jNY98oBpIHjet1LGYwAiW0Y/edit
2. Select Extensions > Apps Script. Paste Code.gs, save.
3. Deploy > New deployment > Web app. Execute as: Me. Access: Anyone (required for no-login test; school approval recommended). Click Deploy and authorize Google permissions.
4. Your supplied Web App URL is already configured in index.html. You do not need to paste it again.
5. Confirm the deployed Apps Script is the provided Code.gs version (if you changed Code.gs, deploy a new version).
6. Publish index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png on GitHub Pages or Netlify (HTTPS). Do not publish Code.gs if you prefer keeping backend code private.
7. On Android, pick teacher > term > subject > section > student. Play the entire sample audio. Answer three questions correctly.
8. Open Google Sheets: Lesson Completions and Quiz Attempts. Verify new rows (web app cross-origin responses are opaque).
9. IMPORTANT: This is a TEST workflow. Name selection is not authentication. A student could impersonate another; recorded audio finish is client-reported and can be forged. Use school-approved authentication and permissions before using for official attendance/grades. Limit teacher access to the private Sheet.
10. If old web app version is deployed, redeploy a New version whenever Code.gs changes. If website still shows older version, refresh or clear the site's cache.
