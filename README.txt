TTVHS Learning Hub installable website

Upload ALL five files in this folder to your Netlify or GitHub Pages site at the same level. For GitHub Pages, index.html is the homepage. Serve via HTTPS.

On Android, open the published site in Chrome and tap Add to Home Screen. The browser may show its install prompt if eligible; otherwise the website gives manual instructions. Websites cannot silently install shortcuts.

If your site already has an index.html, replace it only if you intend to replace its homepage. Do not upload the zip itself as a Github Pages file; unzip first. For Netlify, you can deploy the folder directly.
